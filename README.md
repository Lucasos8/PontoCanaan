PontoCanaan

Sistema web para controle de ponto desenvolvido em Node.js.

Tecnologias
Node.js
Express
EJS
MySQL
Express Session
Luxon
Funcionalidades
Cadastro de usuários
Registro de entrada
Registro de intervalo
Registro de retorno
Registro de saída
Exportação de relatórios
